# House builder

A 3D make-your-own-house sandbox for a six-year-old. One self-contained HTML
file — no build step, no dependencies, and it makes no network requests at all
once the page has loaded. Works on an iPad, an iPhone and a desktop browser.

This repository is only the published page; the source lives elsewhere.

## 霸王的大陆 · 中文版（`bawang/`）

A modern-graphics remake of the Famicom RPG 霸王的大陆 (Destiny of an Emperor),
in Chinese. Open `bawang/index.html` in a browser — static files only, no build
step, no network requests.

- **Look**: painterly procedurally-drawn overworld (soft coastlines, animated
  water, drifting clouds), lit dungeons with torch light, Chinese-style towns,
  glass/gold UI, animated battles with particle effects.
- **Systems** (kept to the original): party of up to 7 generals (5 in front,
  2 back-up who step in when a front general falls); soldiers = HP; shared
  party level; a strategist (军师) whose intelligence decides the tactics the
  army knows; shared tactic points; 全军突击 auto-battle; retreat; food that runs
  down on the march (soldiers desert when it runs out); inns, weapon/armor/item/
  food shops, taverns to recruit generals, enemy generals who may surrender
  after battle; random encounters by region; maze-like forts with treasure and a
  boss at the end; gates that open as the story advances.
- **Story covered**: 黄巾之乱 (程远志 → 张宝 → 张梁 → 张角) and 讨伐董卓
  (华雄 → 吕布 → 董卓), ending with 第一部 完.
- **Controls**: arrow keys / WASD, Enter/Space/Z to confirm, Esc/X for menu;
  on-screen pad and A/B buttons on touch screens. Progress saves at inns.
